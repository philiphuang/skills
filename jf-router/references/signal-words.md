## 2. 模糊词归类

| 用户说的 | 默认归类 | 明确例外 |
|---------|---------|---------|
| 需求 | jf-mrd | 功能需求/AC → jf-prd |
| 设计 | jf-ia | 线框 → jf-wireframe；生成 → jf-uxprompt |
| 页面 | jf-ia | 画线框 → jf-wireframe；生成页面 → jf-uxprompt |
| 数据 | jf-mrd | 建表/数据库/字段 → jf-data |
| 状态 | jf-mrd | 状态变体 → jf-wireframe |
| 权限 | jf-prd | 页面权限 → jf-ia |
| 生成/写代码 | jf-uxprompt | 2.0全部完成 → 4.0 |
| 测试 | jf-test | 无AC时从 jf-prd 开始 |
| 评审/汇报 | jf-review | 无产出时从 jf-mrd 开始 |
| 组件 | jf-wireframe | 编码实现 → 4.0 |

## 3. 路由优先级

```
jf-mrd (1.0)
  ↓
jf-prd (2.0)
  ↓
jf-ia ≈ jf-data (2.0)
  ↓
jf-wireframe (2.0)
  ↓
jf-uxprompt (2.0)
  ↓
jf-test (3.0)
  ↓
4.0 通用开发
```

- 层号越小越优先（从源头）
- 同层内按 PRD → IA/Data → Wireframe → UXPrompt 顺序
- jf-review 特殊：有产出物才做，无产出指向 jf-mrd
