# Knowledge Base Categories

> 默认分类的权威定义在 `scripts/classify.py:DEFAULT_CATEGORIES`，本文件是分类规则的人工可读说明。

预定义分类目录，位于 `知识库/` 下：

- 会议纪要/
- 方案设计/
- 需求文档/
- 技术资料/
- 合同协议/
- 汇报材料/
- 参考资料/
- 客户提供/
- 其他/

## 分类规则

1. 读取 Markdown 内容
2. 读取 `知识库/` 下已有目录结构
3. 使用 LLM 判断最匹配的预定义目录
4. 置信度高 → 直接移动
5. 置信度低 → 询问用户

LLM 需给出单一明确分类 + 理由；若给出多个可能或表示不确定 → 等同于置信度低。
