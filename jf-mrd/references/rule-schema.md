# 规则本体参考

> jf-mrd 的技术参考——规则 schema、标签体系、来源追溯、状态生命周期。
> 在需要查阅字段定义、打标签、追溯来源、判断状态时加载。

## 原始层条目的 6 个字段

| 字段 | 类型 | 必填 | 示例 |
|------|------|------|------|
| **规则ID** | string (BR-NN) | ✓ | BR-07 |
| **[原话]** | string | ✓ | "金额大的活动要走财务审" |
| **[解读]** | string | ✓ | "营销活动金额 > 5000 需财务审核" |
| **标签** | string[] | ✓ | [金额][审批] #营销活动 |
| **来源** | string | ✓ | 会议 2026-08-01 / 章程§3.2 |
| **状态** | enum | ✓ | 候选 |

**[原话] 与 [解读] 分离**：原话保真不动，解读 agent 标注待确认。解决"客户说的 ≠ 客户要的"。

## 标签体系

**预定义主分类**（必打 ≥1 个）：金额 / 审批 / 边界 / 状态转换 / 权限 / 时效

**自由标签**（随手打）：实体(#活动 #订单)、场景(#营销 #核销)、优先级(#P0 #P1)

## 来源追溯

| 来源类型 | 格式 | 置信度 |
|---------|------|--------|
| 会议/访谈 | 会议 2026-08-01 | 中 |
| 章程/文件 | 章程§3.2 | 高 |
| 竞品推断 | 竞品推断·竞品A | 低 |
| 裸输入 | 用户直接输入 | 中 |

冲突裁决时的来源优先级（仅作参考，不做自动裁决）：**章程 > 会议口述 > 竞品推断**

## 规则状态生命周期

```
候选 → 已确认 → 已入MRD → 被修订 / 废止
                              ↓
                  旧规则不删，标记状态，保留追溯
```

| 状态 | 触发条件 |
|------|---------|
| 候选 | agent 提取 |
| 已确认 | 用户确认 |
| 已入MRD | 入库后下游可引用 |
| 被修订 | 增量合并时人工裁决采新 |
| 废止 | 业务变化 |
